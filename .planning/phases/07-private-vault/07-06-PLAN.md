## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vault -> app cache | decrypted copies are written to cacheDir/vault_view for display and sharing |
| vault -> public storage | unhide writes files back where other apps can read them |
| vault -> share targets | Share hands decrypted copies to another app |
